# NLP Getting Started — Text Classification

## О проекте

Проект посвящён решению задачи классификации текстов из соревнования **Kaggle NLP Getting Started**.

Цель модели — определить класс текста на основе его содержания. В качестве основного подхода используется классический NLP pipeline:

**текст → TF-IDF → Logistic Regression → предсказание класса**

Несмотря на отсутствие нейросетевых архитектур, такой подход показывает хороший результат на коротких текстах и является сильным baseline для задач классификации.

## Датасет

Используется датасет соревнования Kaggle **NLP Getting Started**.

Основные данные:

- `train.csv` — обучающая выборка;
- `test.csv` — тестовая выборка;
- `text` — текст сообщения;
- `target` — целевая переменная;
- `id` — идентификатор объекта.

## Используемый подход

### 1. Предобработка текста

Пропущенные значения в текстовом поле заменяются на пустую строку:

```python
train_text = X_train['text'].fillna("")
test_text = df_test['text'].fillna("")
```

### 2. TF-IDF

Для преобразования текста в числовые признаки используется `TfidfVectorizer`.

```python
vectorizer = TfidfVectorizer(
    ngram_range=(1, 2),
    min_df=2,
    max_features=200000,
    sublinear_tf=True
)
```

Используются:

- **unigrams** — отдельные слова;
- **bigrams** — пары слов;
- `min_df=2` — игнорирование слишком редких слов;
- `max_features=200000` — ограничение числа признаков;
- `sublinear_tf=True` — логарифмическое масштабирование частоты слова.

В результате каждый текст представляется разреженным вектором TF-IDF признаков.

### 3. Logistic Regression

Для классификации используется логистическая регрессия:

```python
model = LogisticRegression(
    C=2.0,
    solver="lbfgs",
    max_iter=300
)
```

Логистическая регрессия хорошо подходит для TF-IDF, поскольку способна эффективно работать с большим количеством разреженных признаков.

## Результат

На Kaggle решение показывает результат около:

**F1-score: ~0.80**

Это показывает, что даже классический подход на основе TF-IDF способен дать хороший результат без использования BERT или других больших языковых моделей.

## Возможные улучшения

Текущая версия является baseline-решением. Качество можно улучшить с помощью:

- более тщательной очистки текста;
- настройки параметров `TfidfVectorizer`;
- подбора `C` для Logistic Regression;
- использования word и character n-грамм;
- ансамблей нескольких моделей;
- современных transformer-моделей, например BERT.

Следующим этапом проекта может быть сравнение **TF-IDF + Logistic Regression** с **BERT**, чтобы проверить, насколько использование контекстных представлений улучшает качество классификации.

## Вывод

TF-IDF в сочетании с Logistic Regression оказался эффективным решением для данной задачи. Несмотря на простоту модели, она позволяет получить результат около 0.80 F1-score и служит хорошей отправной точкой перед переходом к более сложным NLP-моделям.
