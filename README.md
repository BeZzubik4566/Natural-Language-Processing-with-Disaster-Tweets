# Natural-Language-Processing-with-Disaster-Tweets
Twitter стал важным каналом коммуникации в чрезвычайных ситуациях. Благодаря повсеместному распространению смартфонов люди могут сообщать о наблюдаемых ими происшествиях в режиме реального времени. Однако не всегда очевидно, действительно ли сообщение пользователя говорит о катастрофе.
